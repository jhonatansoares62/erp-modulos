## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Webhook -> IdempotencyService | wamid e PII implicito (id Meta — pode correlacionar com cliente); deve ser tratado em log debug apenas |
| IdempotencyService -> Repository (native query) | Native query usa parametros nomeados (`:wamid` etc) — sem SQL injection |
| 2 threads concurrent -> mesma row UNIQUE | ON CONFLICT atomico no DB OU UNIQUE constraint + try/catch (fallback) — ambos atomicos no commit boundary |
