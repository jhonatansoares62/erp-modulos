    **Pontos criticos:**
    - `@SpringBootTest(MOCK)` — full app context sem network port. MockMvc roteia direto pelo DispatcherServlet.
    - `@AutoConfigureMockMvc` — registra MockMvc bean.
    - `@ActiveProfiles("test")` — usa application-test.yml com H2 PG-mode + appSecret dummy.
    - `properties.getAppSecret()` lido em runtime — mesmo secret que o Filter usa para validar HMAC. Sem essa simetria, o Filter rejeita 401 e o test falha.
    - `HexFormat.of().formatHex(...)` — Java 17+ utility para hex encoding lowercase (compativel com Meta `sha256=<lowercase hex>`).
    - JdbcTemplate roda fora da transacao do MockMvc — le state committed. Em particular, valida REQUIRES_NEW commit imediato (SC-5).

    **Sequencia critica de runtime:**
    1. Test chama `postFixture(...)` que assina + faz POST

    3. Filter valida assinatura (ja correta — calculada com mesmo secret)
    4. Filter delega ao `WebhookController.receber` com request embrulhado em `CachedBodyHttpServletRequest`

    6. Service: parser → idempotency → cliente — tudo SINCRONO em Phase 2
